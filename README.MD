Assignment Day 6 - Mini Project (HTML, CSS & Tailwind CSS)

Repository ini berisi pengerjaan Mini Project untuk program Full Stack Web Development. Fokus utamanya adalah membandingkan pembuatan antarmuka web (landing page dan katalog produk bertema AI Tools) memakai dua pendekatan berbeda: Vanilla CSS murni dan Tailwind CSS v4.

Ringkasan Proyek

Proyek ini dibagi menjadi dua bagian tugas utama:

1.1. Tugas 1 - TUGAS1(HTMLCSS)
Membangun katalog produk menggunakan HTML semantik dan Pure Vanilla CSS. Mengimplementasikan layout dengan Flexbox, CSS Grid, media query untuk tampilan responsif, serta styling komponen dasar seperti kartu produk dan tombol.

1.2. Tugas 2 - TUGAS2(HTMLTAILWIND)
Membangun landing page direktori AI Tools menggunakan Tailwind CSS v4 via CDN. Memanfaatkan konfigurasi @theme, utility classes, reusable @layer components, Hero section dengan overlay, serta tampilan grid untuk kategori dan produk yang sedang trending.

Detail Tugas & Fitur

3.1. Tugas 1: Katalog Produk (Vanilla CSS)

Sticky Navigation Bar dengan logo dan menu.

Section header untuk judul dan deskripsi katalog.

Filter kategori dan toolbar pencarian produk.

Grid produk responsif dengan informasi harga Rupiah dan tombol Add to Cart.

Murni menggunakan CSS Grid, Flexbox, dan hover transition sederhana.

3.2. Tugas 2: AI Tools Landing Page (Tailwind CSS v4)

Integrasi Tailwind CSS v4 via CDN dengan konfigurasi @theme untuk kustomisasi warna brand.

Komponen yang dapat dipakai ulang menggunakan @layer components (seperti tombol dan kartu).

Hero section dengan background overlay dark dan tombol Call to Action.

Grid kategori tools (Productivity, Marketing, Code, dan lain-lain).

Section produk unggulan (Featured Product) dan daftar Trending Tools dengan efek hover.

Teknologi yang Digunakan

HTML5: Struktur halaman semantik.

CSS3: Layouting murni (Flexbox, Grid, Media Queries).

Tailwind CSS v4: Utility-first framework untuk styling Tugas 2.

Git dan GitHub: Version control.

Cara Menjalankan Proyek

Karena proyek ini berbasis web statis, tidak diperlukan proses build atau install dependency.

5.1. Menggunakan Extension Live Server (VS Code)
Buka folder proyek di VS Code, klik kanan file index.html dari folder TUGAS1 atau TUGAS2, lalu pilih Open with Live Server.

5.2. Menggunakan Local Server (Laragon/XAMPP)
Simpan folder di direktori root server lokal Anda (misal C:\laragon\www), lalu buka melalui URL:

http://localhost/PracticalSessionDay12/TUGAS1(HTMLCSS)/index.html

http://localhost/PracticalSessionDay12/TUGAS2(HTMLTAILWIND)/index.html

5.3. Buka Langsung
Cukup klik dua kali file index.html di masing-masing folder untuk membukanya di browser.
